# Sachin Dev

Developer from Nepal building fast, practical web tools with Astro and React. Creator of [NepDate](https://nepdate.xyz) — a free Nepali date converter (BS ↔ AD).

## About Me

I'm Sachin Dev (Sachin Sapkota). I build small, focused web apps — mostly sites and tools that solve a real problem, load fast, and work well on mobile.

My main public project right now is NepDate, a production site for converting Bikram Sambat and Gregorian dates, with an age calculator and English/Nepali versions.

## What I Build

- Static and serverless websites with Astro

- Discord bots and small community tools (including Minecraft server tooling)
- Android app experiments built with AI-assisted workflows
