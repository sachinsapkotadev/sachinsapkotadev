I'm **Sachin Dev** (Sachin Sapkota) from Nepal. I build small, focused web apps — sites and tools that solve a real problem, load fast, and work well on mobile.

My main public work right now is **[NepDate](https://nepdate.xyz)** — a production Nepali date converter (BS ↔ AD) with today's date, an age calculator, and English/Nepali versions. It's live and in use.

I work in small, frequent commits with working builds, and I keep docs next to the code.

## How I Build

| Principle | What it means in practice |
|---|---|
| **Useful first** | If nobody needs it, I don't build it. NepDate exists because date conversion is daily work in Nepal. |
| **Simple > clever** | One page, one job. Fast load, readable code, boring infra that stays up. |
| **Learn by shipping** | Real users beat tutorials — launch, watch, fix, repeat. |
| **Mobile is the user** | Most visitors are on phones. If it's slow on mobile, it's broken. |
